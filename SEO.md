## What's implemented

**On-page**
- One H1 per page that includes the page's main keyword (the small label above each headline is part of the H1).
- Service sections use keyword H2s (e.g. "Google Ads Management for Search Campaigns").
- Main keywords appear naturally in the opening copy. Every image has descriptive alt text and dimensions.
- Contextual internal links between Services, Portfolio, FAQ, About and the Entrepreneur Hub.
- Home links point at `/` (the canonical URL), not `index.html`.

**Structured data (JSON-LD, generated by `build.mjs`)**
- Home: `Organization` (logo, contact point, social profiles) + `WebSite`.
- Every inner page: `WebPage` / `AboutPage` / `ContactPage` / `CollectionPage` + `BreadcrumbList`.
- Services: one `Service` per service. FAQ: `FAQPage` with all 8 questions.

**Technical**
- Canonical URL, `robots` meta, Open Graph and Twitter tags on every page; `lang="en-IN"`.
- `sitemap.xml` with real last-modified dates (from git history), and `robots.txt` pointing at it.
- `.htaccess`:
  - HTTPS + non-www redirects
  - `/index.html` and `/docs/…` 301 to their clean URLs (no duplicate content)
  - a real 404 page (`noindex`) instead of serving the homepage
  - source files blocked
  - compression, security headers and long caching
- Speed:
  - WebP images (about 50% smaller), responsive hero image
  - preloaded largest image
  - non-blocking Google Fonts, deferred scripts
  - cache-busted CSS/JS (`?v=` content hash)
- Lighthouse (mobile): 100 in Performance, Accessibility, Best Practices and SEO on the pages tested.

## After each deploy

1. Run `node build.mjs`, commit and push.
2. Spot-check: `https://digifyhub.tech/`, `/sitemap.xml`, `/robots.txt`, a missing page (should show the 404 page).

## One-time setup to finish (needs your accounts)

- [ ] **Google Search Console**
  1. Add property `https://digifyhub.tech` (Domain property via DNS is best).
  2. If you choose the HTML-tag method, paste the code into `src/site.json` → `googleSiteVerification`, rebuild and deploy.
  3. Submit `https://digifyhub.tech/sitemap.xml`. Use URL Inspection → Request indexing for the home page.
- [ ] **Bing Webmaster Tools**: import from Search Console, or put the code in `bingSiteVerification`.
- [ ] **Google Analytics 4**: put the Measurement ID (`G-XXXXXXX`) in `src/site.json` → `ga4Id`, then rebuild. Form submissions already send a `generate_lead` event; mark it as a key event in GA4.
- [ ] **Google Business Profile**: create or verify it, and use exactly the same name, phone and website as the site.
- [ ] Hostinger hPanel: confirm SSL is active and "Force HTTPS" is on.
- [ ] Add the real Instagram URL (`src/site.json` → `social.instagram`). It is added to the footer and to the structured data automatically.

## Ongoing (what moves rankings from here)

- Publish the blog articles listed on the Blog page (800–1,500 words each). Link each one to the matching service section.
- Add real case studies with verified results as projects complete.
- Collect Google reviews from happy clients.
- Get listed in reputable local and industry directories with consistent contact details.
- Check Search Console monthly for coverage errors, Core Web Vitals and the queries you appear for.
